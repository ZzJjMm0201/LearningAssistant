**示例格式（以一道数学题为例）：**

**题目：** 已知二次函数 \( y = x^2 - 4x + 3 \)，求其顶点坐标、对称轴方程，并画出函数图像。

**解题过程：**

1. **配方求顶点**  
   将一般式化为顶点式：  
   \[
   y = x^2 - 4x + 3 = (x^2 - 4x + 4) - 4 + 3 = (x - 2)^2 - 1
   \]  
   所以顶点坐标为 \((2, -1)\)，对称轴为直线 \(x = 2\)。

2. **求与坐标轴交点**  
   - 与 \(y\) 轴交点：令 \(x = 0\)，得 \(y = 3\)，即 \((0, 3)\)。  
   - 与 \(x\) 轴交点：令 \(y = 0\)，解 \(x^2 - 4x + 3 = 0\)，得 \((x - 1)(x - 3) = 0\)，即 \((1, 0)\) 和 \((3, 0)\)。

3. **绘制函数图像**  
   使用 TikZ 绘制抛物线，标注关键点。

```latex
\documentclass{standalone}
\usepackage{tikz}
\begin{document}
\begin{tikzpicture}[scale=0.8]
  % 坐标轴
  \draw[->] (-1,0) -- (5,0) node[right] {$x$};
  \draw[->] (0,-2) -- (0,5) node[above] {$y$};
  % 网格
  \draw[gray!30, thin] (-1,-2) grid (5,5);
  % 抛物线
  \draw[domain=-0.5:4.5, smooth, thick, blue] plot (\x, {\x*\x - 4*\x + 3});
  % 标注顶点
  \filldraw[red] (2,-1) circle (2pt) node[below right] {顶点 $(2,-1)$};
  % 标注与x轴交点
  \filldraw[red] (1,0) circle (2pt) node[below] {$(1,0)$};
  \filldraw[red] (3,0) circle (2pt) node[below] {$(3,0)$};
  % 标注与y轴交点
  \filldraw[red] (0,3) circle (2pt) node[left] {$(0,3)$};
  % 对称轴
  \draw[dashed, red] (2,-2) -- (2,5) node[above] {对称轴 $x=2$};
\end{tikzpicture}
\end{document}
```
