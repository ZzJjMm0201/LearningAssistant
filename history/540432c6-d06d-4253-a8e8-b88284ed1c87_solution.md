# 解题结果

## 解题思路

### 解题思路

**第一步：解不等式①**  
原不等式 \(2x^2 - 3x - 2 \ge 0\) 可因式分解为 \((2x+1)(x-2) \ge 0\)。  
解得 \(x \le -\frac{1}{2}\) 或 \(x \ge 2\)。  
**关键点**：注意二次项系数为正，不等号方向与根的关系。

**第二步：解不等式②**  
原不等式 \(\frac{x-1}{x-3} \le 0\) 等价于 \((x-1)(x-3) \le 0\) 且 \(x \neq 3\)。  
解得 \(1 \le x < 3\)。  
**易错提醒**：分母不能为零，所以 \(x=3\) 要排除。

**第三步：求交集**  
将两个解集在数轴上表示，取公共部分：  
①的解集为 \((-\infty, -\frac{1}{2}] \cup [2, +\infty)\)，②的解集为 \([1, 3)\)。  
交集为 \([2, 3)\)。

**最终答案**：\([2, 3)\)  
**突破口**：正确解出每个不等式，特别注意分式不等式的分母限制条件。

## 完整解析

### 完整解题过程

#### 第一步：解不等式① \(2x^2 - 3x - 2 \ge 0\)

因式分解：
\[
2x^2 - 3x - 2 = (2x + 1)(x - 2) \ge 0
\]

令 \((2x + 1)(x - 2) = 0\)，得两根：
\[
x_1 = -\frac{1}{2}, \quad x_2 = 2
\]

由于二次项系数 \(2 > 0\)，抛物线开口向上，不等式 \(\ge 0\) 的解集为两根之外：
\[
x \le -\frac{1}{2} \quad \text{或} \quad x \ge 2
\]

用区间表示为：
\[
(-\infty, -\frac{1}{2}] \cup [2, +\infty)
\]

#### 第二步：解不等式② \(\frac{x-1}{x-3} \le 0\)

分式不等式等价于：
\[
(x - 1)(x - 3) \le 0 \quad \text{且} \quad x - 3 \neq 0
\]

令 \((x - 1)(x - 3) = 0\)，得两根：
\[
x_1 = 1, \quad x_2 = 3
\]

由于二次项系数 \(1 > 0\)，抛物线开口向上，不等式 \(\le 0\) 的解集为两根之间：
\[
1 \le x \le 3
\]

但分母 \(x - 3 \neq 0\)，即 \(x \neq 3\)，所以解集为：
\[
1 \le x < 3
\]

用区间表示为：
\[
[1, 3)
\]

#### 第三步：求交集 \(A \cap B\)

\[
A = (-\infty, -\frac{1}{2}] \cup [2, +\infty), \quad B = [1, 3)
\]

在数轴上表示两个集合，取公共部分：

```latex

\usepackage{tikz}
\begin{document}
\begin{tikzpicture}[scale=1.2]
  % 数轴
  \draw[->] (-3.5,0) -- (4.5,0) node[right] {$x$};
  % 刻度
  \foreach \x in {-3,-2,-1,0,1,2,3,4}
    \draw (\x,0.1) -- (\x,-0.1) node[below] {$\x$};
  % 集合A：(-∞,-1/2] ∪ [2,+∞)
  \draw[thick,blue] (-3.5,0.3) -- (-0.5,0.3);
  \draw[fill=blue] (-0.5,0.3) circle (2pt);
  \draw[thick,blue] (2,0.3) -- (4.5,0.3);
  \draw[fill=blue] (2,0.3) circle (2pt);
  \node[blue,above] at (-2,0.5) {$A$};
  \node[blue,above] at (3.2,0.5) {$A$};
  % 集合B：[1,3)
  \draw[thick,red] (1,0.15) -- (3,0.15);
  \draw[fill=red] (1,0.15) circle (2pt);
  \draw[fill=white,draw=red] (3,0.15) circle (2pt);
  \node[red,below] at (2,-0.3) {$B$};
  % 交集：[2,3)
  \draw[thick,green!60!black] (2,0) -- (3,0);
  \draw[fill=green!60!black] (2,0) circle (2pt);
  \draw[fill=white,draw=green!60!black] (3,0) circle (2pt);
  \node[green!60!black,above] at (2.5,0.3) {$A \cap B$};
\end{tikzpicture}
\end{document}
```

从数轴可以看出，两个集合的公共部分为：
\[
[2, 3)
\]

#### 第四步：写出答案

\[
\boxed{A \cap B = [2, 3)}
\]
