# 解题结果

## 解题思路

### 解题思路

**第一步：识别函数形式**  
已知函数 \( f(x) = x^2 + 2x - 1 \) 是一个多项式函数，由三项组成：\( x^2 \)、\( 2x \) 和常数项 \(-1\)。

**第二步：应用求导法则**  
根据导数的基本公式：
- 幂函数求导：\( (x^n)' = n x^{n-1} \)，所以 \( (x^2)' = 2x \)。
- 常数倍函数求导：\( (k \cdot x)' = k \)，所以 \( (2x)' = 2 \)。
- 常数项求导：常数的导数为 0，所以 \( (-1)' = 0 \)。

**第三步：合并结果**  
将各项导数相加：  
\( f'(x) = 2x + 2 + 0 = 2x + 2 \)。

**关键突破口**  
牢记多项式求导的“逐项求导，系数不变”原则，尤其是常数项导数为 0 这一易错点。本题直接套用公式即可，无需复杂技巧。

## 完整解析

### 解题过程

**步骤1：明确函数形式**  
已知函数 \( f(x) = x^{2} + 2x - 1 \)，这是一个二次多项式函数，由三项组成：\( x^{2} \)、\( 2x \) 和常数项 \(-1\)。

**步骤2：应用导数基本公式**  
根据导数的线性性质和基本求导公式：
- 幂函数求导：\( \frac{d}{dx}(x^{n}) = n x^{n-1} \)，所以 \( \frac{d}{dx}(x^{2}) = 2x^{2-1} = 2x \)。
- 常数倍函数求导：\( \frac{d}{dx}(k \cdot x) = k \)，所以 \( \frac{d}{dx}(2x) = 2 \)。
- 常数项求导：常数的导数为 0，所以 \( \frac{d}{dx}(-1) = 0 \)。

**步骤3：合并各项导数**  
将各项导数相加：
\[
f'(x) = \frac{d}{dx}(x^{2}) + \frac{d}{dx}(2x) + \frac{d}{dx}(-1) = 2x + 2 + 0 = 2x + 2
\]

**步骤4：验证结果（可选）**  
导函数 \( f'(x) = 2x + 2 \) 是一条直线，斜率为 2，截距为 2。原函数 \( f(x) \) 在 \( x = -1 \) 处取得最小值（因为 \( f'(x) = 0 \) 时 \( x = -1 \)），与二次函数顶点公式一致。

**最终答案**  
\[
\boxed{f'(x) = 2x + 2}
\]

│   │   └── 对 x² 求导：2x

├── 合并结果
