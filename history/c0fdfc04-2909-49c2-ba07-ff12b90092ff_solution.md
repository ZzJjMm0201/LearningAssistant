### 完整解题过程

#### 第一步：分析抛物线开口方向
观察图像，抛物线开口向下，因此二次项系数：
\[
a < 0
\]

#### 第二步：分析对称轴位置
对称轴在 \(y\) 轴右侧，即对称轴 \(x = -\frac{b}{2a} > 0\)。  
已知 \(a < 0\)，则 \(-\frac{b}{2a} > 0\) 等价于 \(-\frac{b}{2a} > 0 \Rightarrow -b < 0 \Rightarrow b > 0\)。  
因此：
\[
b > 0
\]

#### 第三步：分析抛物线与 \(y\) 轴交点
抛物线与 \(y\) 轴交于正半轴，即当 \(x = 0\) 时，\(y = c > 0\)。  
因此：
\[
c > 0
\]

#### 第四步：分析抛物线与 \(x\) 轴交点个数
抛物线与 \(x\) 轴有两个交点，说明一元二次方程 \(ax^2 + bx + c = 0\) 有两个不相等的实数根，故判别式：
\[
\Delta = b^2 - 4ac > 0
\]

#### 第五步：综合判断选项
根据以上分析，正确的结论应为：
\[
a < 0,\quad b > 0,\quad c > 0,\quad \Delta > 0
\]
对照选项，选择符合此符号关系的选项即可。
