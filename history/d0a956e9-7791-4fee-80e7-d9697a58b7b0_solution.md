## 完整解析

```latex
\documentclass{article}
\usepackage{amsmath}
\begin{document}

\section*{解题过程}

已知函数 $f(x) = x^3 + 2x - 1$，求其导数 $f'(x)$。

\textbf{步骤1：} 根据导数的线性性质，对多项式逐项求导。

\textbf{步骤2：} 应用幂函数求导公式：若 $y = x^n$，则 $y' = nx^{n-1}$。

- 第一项：$x^3$ 的导数为 $3x^{3-1} = 3x^2$。
- 第二项：$2x$ 的导数为 $2 \cdot 1 \cdot x^{1-1} = 2$。
- 第三项：常数 $-1$ 的导数为 $0$。

\textbf{步骤3：} 将各项导数相加，得到：

\[
f'(x) = 3x^2 + 2 + 0 = 3x^2 + 2
\]

\textbf{答案：} $\boxed{f'(x) = 3x^2 + 2}$

\end{document}
```

**知识点：**导数的计算、幂函数求导法则

    └── 应用条件：n为任意实数
└── 解题步骤

    │   ├── x^3 → 3x^2
    │   ├── 2x → 2
    │   └── -1 → 0
    └── 合并结果：f'(x) = 3x^2 + 2
└── 易错提醒
