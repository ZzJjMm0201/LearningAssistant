\section*{解题过程}

已知函数 $f(x) = x^3 + 2x - 1$，求其导数 $f'(x)$。

\textbf{步骤1：} 识别函数结构。该函数为多项式函数，由三项组成：$x^3$、$2x$ 和常数 $-1$。根据导数的线性性质，可以逐项求导再相加。

\textbf{步骤2：} 应用基本求导公式：
\begin{itemize}
    \item 对于 $x^n$，导数为 $nx^{n-1}$。因此，$(x^3)' = 3x^{3-1} = 3x^2$。
    \item 对于 $kx$（$k$为常数），导数为 $k$。因此，$(2x)' = 2$。
    \item 对于常数 $c$，导数为 $0$。因此，$(-1)' = 0$。
\end{itemize}

\textbf{步骤3：} 合并各项导数：
\[
f'(x) = 3x^2 + 2 + 0 = 3x^2 + 2
\]

\textbf{答案：}
\[
\boxed{f'(x) = 3x^2 + 2}
\]

## 思维导图

核心概念：求多项式函数的导数
└── 识别函数结构
    ├── 多项式函数：f(x) = x^3 + 2x - 1
    └── 由三项组成：幂函数、一次项、常数项
└── 应用基本求导公式
    ├── 幂函数求导公式：d/dx (x^n) = n*x^(n-1)
    │   ├── 对 x^3 求导：3x^2
    │   └── 注意：指数减1，系数乘原指数
    ├── 一次项求导：d/dx (kx) = k
    │   └── 对 2x 求导：2
    └── 常数求导：d/dx (c) = 0
        └── 对 -1 求导：0
└── 合并结果
    ├── f'(x) = 3x^2 + 2 + 0
    └── 最终答案：f'(x) = 3x^2 + 2
└── 验证与易错点
    ├── 检查：导数是否逐项正确
    ├── 易错：忘记常数项导数为0
    └── 易错：幂函数指数减1时出错（如写成3x^3）
