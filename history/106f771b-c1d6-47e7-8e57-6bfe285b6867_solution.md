### 解题过程

#### 第一步：观察图像，确定开口方向
图像开口向上，因此二次项系数 \( a > 0 \)。

#### 第二步：确定对称轴位置
对称轴在 \( y \) 轴右侧，即 \( x = -\frac{b}{2a} > 0 \)。  
因为 \( a > 0 \)，所以 \( -\frac{b}{2a} > 0 \Rightarrow b < 0 \)。

#### 第三步：确定与 \( y \) 轴交点
图像与 \( y \) 轴交于正半轴，即当 \( x = 0 \) 时，\( y = c > 0 \)。

#### 第四步：判断与 \( x \) 轴交点个数
图像与 \( x \) 轴有两个交点，因此判别式 \( \Delta = b^2 - 4ac > 0 \)。

#### 第五步：综合结论
由以上分析可得：
- \( a > 0 \)
- \( b < 0 \)
- \( c > 0 \)
- \( \Delta > 0 \)

根据这些符号关系，可以判断选项中关于系数符号、判别式正负的结论是否正确。
