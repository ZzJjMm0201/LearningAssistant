### 解题思路

**第一步：识别正态密度函数参数**  
题目给出正态密度函数 \( f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}} \)，对比已知函数 \( f(x) = \cdot e^{-\frac{(x+3)^2}{4}} \)，可得：  
- 指数部分 \( (x+3)^2 = (x - (-3))^2 \)，所以 \( \mu = -3 \)。  
- 分母 \( 2\sigma^2 = 4 \)，解得 \( \sigma^2 = 2 \)，即 \( \sigma = \sqrt{2} \)。  
因此答案为 D。

**第二步：利用正态分布对称性求概率**  
对于第5题，\( X \sim N(\mu, \sigma^2) \)，已知 \( P(X \geq 9) = 0.2 \)，由对称性知 \( P(X \leq 3) = 0.2 \)，则 \( P(3 < X < 9) = 1 - 0.2 - 0.2 = 0.6 \)。  
第6题类似，利用 \( P(X < 0) + P(X < 3) = 1.1 \) 及对称性 \( P(X < 0) = P(X > 2) \)，可逐步求出 \( P(2 < X < 3) = 0.1 \)。

**关键突破口**：  
- 熟记正态密度函数的标准形式，准确对应 \( \mu \) 和 \( \sigma \)。  
- 灵活运用正态曲线关于 \( x = \mu \) 对称的性质，将概率转化为对称区间计算。

## 完整解题过程

### 题目1：正态密度函数参数识别

**已知：** 随机变量 \(X\) 的正态密度函数为  
\[
f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \quad x \in (-\infty, +\infty)
\]  
题目给出：  
\[
f(x) = \cdot e^{-\frac{(x+3)^2}{4}}
\]  
（此处省略了系数 \(\frac{1}{\sqrt{2\pi}\sigma}\)，但形式一致）

**步骤1：确定 \(\mu\)**  
指数部分为 \(-\frac{(x+3)^2}{4}\)，标准形式为 \(-\frac{(x-\mu)^2}{2\sigma^2}\)。  
对比得：\(x+3 = x - (-3)\)，所以 \(\mu = -3\)。

**步骤2：确定 \(\sigma\)**  
由 \(2\sigma^2 = 4\)，得 \(\sigma^2 = 2\)，所以 \(\sigma = \sqrt{2}\)。

**答案：** D. \(\mu = -3, \sigma = \sqrt{2}\)

### 题目5：正态分布概率计算

**已知：** \(X \sim N(\mu, \sigma^2)\)，且 \(P(X \geq 9) = 0.2\)，求 \(P(6 < X < ?)\)（题目中未明确上界，但根据常见题型，应为 \(P(6 < X < 9)\)）

**步骤1：利用对称性**  
正态曲线关于 \(x = \mu\) 对称。由 \(P(X \geq 9) = 0.2\)，根据对称性得：  
\[
P(X \leq 2\mu - 9) = P(X \leq 2\mu - 9) = 0.2
\]  
但题目未给出 \(\mu\)，需从条件推断。常见情况是 \(\mu = 6\)（因为 \(6\) 是 \(9\) 的对称点），则：  
\[
P(X \leq 3) = 0.2
\]

**步骤2：计算区间概率**  
\[
P(6 < X < 9) = P(X < 9) - P(X \leq 6) = (1 - 0.2) - 0.5 = 0.3
\]  
（若 \(\mu = 6\)，则 \(P(X \leq 6) = 0.5\)）

**答案：** 0.3（选项C）

### 题目6：正态分布概率计算

**已知：** \(X \sim N(1, \sigma^2)\)，且 \(P(X < 0) + P(X < 3) = \frac{11}{10}\)，求 \(P(2 < X < 3)\)。

**步骤1：利用对称性**  
正态曲线关于 \(x = 1\) 对称，所以：  
\[
P(X < 0) = P(X > 2)
\]  
且 \(P(X < 3) = P(X > -1)\)，但更直接的是：  
\[
P(X < 0) = P(X > 2) = 1 - P(X \leq 2)
\]

**步骤2：建立方程**  
设 \(a = P(X < 0) = P(X > 2)\)，则 \(P(X < 3) = 1 - P(X \geq 3)\)。  
由对称性，\(P(X \geq 3) = P(X \leq -1)\)，但不易直接。  
更简单：因为 \(P(X < 0) + P(X < 3) = 1.1\)，且 \(P(X < 0) + P(X > 2) = 2a\)，而 \(P(X < 3) = 1 - P(X \geq 3)\)，且 \(P(X \geq 3) = P(X \leq -1)\)。  
但最优方法：利用正态分布总概率为1，且对称性得：  
\[
P(X < 0) + P(X < 3) = [P(X < 0) + P(X > 2)] + P(0 \leq X \leq 2) = 2a + P(0 \leq X \leq 2)
\]  
而 \(P(0 \leq X \leq 2) = 0.6826\)（若 \(\sigma\) 已知），但此处 \(\sigma\) 未知，需用另一种方法。

**步骤3：直接计算**  
由对称性：\(P(X < 0) = P(X > 2)\)，且 \(P(X < 3) = 1 - P(X \geq 3)\)。  
又 \(P(X \geq 3) = P(X \leq -1)\)，所以：  
\[
P(X < 0) + P(X < 3) = P(X < 0) + 1 - P(X \leq -1) = 1 + [P(X < 0) - P(X \leq -1)]
\]  
由于 \(P(X < 0) - P(X \leq -1) = P(-1 \leq X < 0)\)，且由对称性 \(P(-1 \leq X < 0) = P(2 < X \leq 3)\)，所以：  
\[
1 + P(2 < X < 3) = \frac{11}{10} \Rightarrow P(2 < X < 3) = 0.1
\]

**答案：** A. 0.1

### 题目7：正态曲线最高点

**已知：** 正态变量落在区间 \((0.2, +\infty)\) 内的概率为0.5，求曲线最高点对应的 \(x\) 值。

**步骤1：理解概率含义**  
正态曲线最高点对应 \(x = \mu\)。概率0.5意味着区间 \((0.2, +\infty)\) 的面积占一半，即 \(0.2\) 是均值 \(\mu\)。

**步骤2：得出结论**  
因此，曲线在 \(x = 0.2\) 处达到最高点。

**答案：** 0.2

### 题目8：二项分布与正态分布综合

**已知：** \(X \sim B(2, p)\)，\(Y \sim N(2, \sigma^2)\)，\(P(X \geq 1) = 0.64\)，\(P(0 \leq Y \leq 2) = p\)，求 \(P(Y > 4)\)。

**步骤1：由二项分布求 \(p\)**  
\[
P(X \geq 1) = 1 - P(X = 0) = 1 - (1-p)^2 = 0.64
\]  
\[
(1-p)^2 = 0.36 \Rightarrow 1-p = 0.6 \Rightarrow p = 0.4
\]

**步骤2：由正态分布求 \(\sigma\)**  
\(P(0 \leq Y \leq 2) = p = 0.4\)，且 \(Y \sim N(2, \sigma^2)\)，所以：  
\[
P(0 \leq Y \leq 2) = P\left(\frac{0-2}{\sigma} \leq Z \leq \frac{2-2}{\sigma}\right) = P\left(-\frac{2}{\sigma} \leq Z \leq 0\right) = 0.4
\]  
查标准正态分布表得：\(P(Z \leq 0) = 0.5\)，所以 \(P\left(-\frac{2}{\sigma} \leq Z \leq 0\right) = 0.5 - P\left(Z < -\frac{2}{\sigma}\right) = 0.4\)，即 \(P\left(Z < -\frac{2}{\sigma}\right) = 0.1\)，查表得 \(-\frac{2}{\sigma} \approx -1.28\)，所以 \(\sigma \approx 1.5625\)。

**步骤3：求 \(P(Y > 4)\)**  
\[
P(Y > 4) = P\left(Z > \frac{4-2}{\sigma}\right) = P\left(Z > \frac{2}{1.5625}\right) = P(Z > 1.28) = 0.1
\]

**答案：** 0.1

### 题目9：标准化变换

**已知：** \(X \sim N(2, 2^2)\)，且 \(aX + b\) 服从标准正态分布 \(N(0, 1)\)，求 \(a, b\)。

**步骤1：标准化公式**  
若 \(X \sim N(\mu, \sigma^2)\)，则 \(\frac{X - \mu}{\sigma} \sim N(0, 1)\)。  
所以 \(aX + b = \frac{X - 2}{2}\)，即 \(a = \frac{1}{2}\)，\(b = -1\)。

**答案：** \(a = \frac{1}{2}\)，\(b = -1\)

### 题目10：身高分布问题

**已知：** 身高 \(X \sim N(172, \sigma^2)\)，样本量1200人，身高在168cm到176cm之间的人数占75%，求身高不低于176cm的人数。

**步骤1：利用概率求 \(\sigma\)**  
\[
P(168 < X < 176) = P\left(\frac{168-172}{\sigma} < Z < \frac{176-172}{\sigma}\right) = P\left(-\frac{4}{\sigma} < Z < \frac{4}{\sigma}\right) = 0.75
\]  
由对称性，\(P\left(0 < Z < \frac{4}{\sigma}\right) = 0.375\)，查表得 \(\frac{4}{\sigma} \approx 1.15\)，所以 \(\sigma \approx 3.478\)。

**步骤2：求不低于176cm的概率**  
\[
P(X \geq 176) = P\left(Z \geq \frac{176-172}{\sigma}\right) = P(Z \geq 1.15) = 0.5 - 0.375 = 0.125
\]

**步骤3：计算人数**  
人数 = \(1200 \times 0.125 = 150\)人。

**答案：** 约150人
