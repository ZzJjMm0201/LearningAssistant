**解题过程**：

1. **配方求顶点**：
   \[
   y = x^2 - 4x + 3 = (x^2 - 4x + 4) - 1 = (x - 2)^2 - 1
   \]
   顶点坐标为 \((2, -1)\)，对称轴为直线 \(x = 2\)。

2. **求与坐标轴交点**：
   - 与 \(y\) 轴交点：令 \(x = 0\)，得 \(y = 3\)，即 \((0, 3)\)。
   - 与 \(x\) 轴交点：令 \(y = 0\)，解 \(x^2 - 4x + 3 = 0\)，得 \((x - 1)(x - 3) = 0\)，即 \((1, 0)\) 和 \((3, 0)\)。

3. **绘制图像**：
   ```latex
   \begin{tikzpicture}
       \begin{axis}[
           axis lines = middle,
           xlabel = $x$, ylabel = $y$,
           xmin = -1, xmax = 5,
           ymin = -2, ymax = 5,
           grid = both,
           width = 10cm,
           height = 8cm
       ]
       \addplot[blue, thick, domain=-1:5] {x^2 - 4*x + 3};
       \addplot[red, mark=*, only marks] coordinates {(2, -1) (0, 3) (1, 0) (3, 0)};
       \node[above right] at (axis cs:2,-1) {顶点 $(2,-1)$};
       \node[above left] at (axis cs:0,3) {$(0,3)$};
       \node[below] at (axis cs:1,0) {$(1,0)$};
       \node[below] at (axis cs:3,0) {$(3,0)$};

       \node[above] at (axis cs:2,5) {对称轴 $x=2$};
       \end{axis}
   \end{tikzpicture}
   ```
