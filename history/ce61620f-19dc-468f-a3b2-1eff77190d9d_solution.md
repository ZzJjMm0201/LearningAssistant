## 完整解析

```latex
\documentclass{article}
\usepackage{amsmath}
\begin{document}

\section*{解题过程}

已知函数 $f(x) = x^3 + 2x - 1$，求导函数 $f'(x)$。

\textbf{第一步：逐项求导}

根据求导法则，对多项式函数逐项求导：

\begin{itemize}
    \item 对于 $x^3$，使用幂函数求导公式 $(x^n)' = nx^{n-1}$，得 $(x^3)' = 3x^2$。
    \item 对于 $2x$，使用常数倍法则 $(cf(x))' = cf'(x)$，且 $(x)' = 1$，得 $(2x)' = 2$。
    \item 对于常数 $-1$，常数的导数为 $0$，即 $(-1)' = 0$。
\end{itemize}

\textbf{第二步：合并结果}

将各项导数相加：
\[
f'(x) = 3x^2 + 2 + 0 = 3x^2 + 2
\]

\textbf{第三步：写出最终答案}

\[
\boxed{f'(x) = 3x^2 + 2}
\]

\end{document}
```
